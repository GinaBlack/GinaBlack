## 🔬 What I'm Building

### 🩻 MeMo3D — AI-Powered Medical Imaging

An AI-integrated platform for transforming **CT scan data into customizable 3D-printable assistive devices**, demonstrated through a wrist-splint proof of concept.

**Core technologies:**

* MONAI 2D U-Net for medical-image segmentation
* Marching Cubes for 3D reconstruction
* Parametric modeling for assistive-device generation
* STL export and mesh optimization
* Three.js/WebGL for browser-based visualization
* PyTorch + FastAPI AI services
* React + Node.js/Express

**Research direction:** AI-assisted medical image analysis and personalized assistive-device design.

---

### 🚦 UTWatch — Multimodal Traffic Accident Detection

A real-time traffic monitoring and accident detection system investigating whether **multimodal sensing can reduce false alarms compared with camera-only approaches** under mixed traffic and inconsistent lighting conditions.

The system combines:

* **YOLOv11n** for object detection
* **ConvLSTM** for spatio-temporal video analysis
* **MFCC-based audio classification** for crash-sound detection
* Decision-level multimodal fusion
* WebSocket-based real-time alerts
* React monitoring dashboard

On the project's held-out test data, the system achieved **perfect accident recall**, a **false-positive rate below 0.02/hour**, and approximately **2.5-second end-to-end latency on a standard CPU**.

### 📍 PinPoint — Digital Addressing for Cameroon

A GPS-based digital addressing platform designed around the challenge of **landmark-dependent addressing and delivery**.

Features include:

* Anonymous and alias-based addresses
* Shareable message-link addresses
* Real-time chat
* GPS-based location services
* English/French bilingual interface
* Subscription-based service model
* Simulated Mobile Money payments

I led a **5-person team** and worked on the product architecture, interface, business model, and project presentation.

### 🎯 Attendr — Intelligent Attendance System

A mobile attendance platform combining:

* Facial recognition
* GPS-based geofencing
* Real-time identity verification
* Location verification
* Attendance history
* Backend/database integration

The project explores how computer vision and location intelligence can be combined to automate attendance verification.
